# data

`cards.json` is generated by `scripts/build-cards.mjs` from `references/pictorial-key/text` and verified by
`scripts/check-cards.mjs`. Do not edit it by hand.

```text
{ book, sectionNotes[], cards[78] }

card = {
  id            "major-00" .. "major-21", "wands-01" .. "pentacles-14" (11 page, 12 knight, 13 queen, 14 king)
  arcana        "major" | "minor"
  number, suit, rank
  name          the book's name ("Strength", "King of Wands"); aliases: other names the book gives
  printedTitle  heading as printed in the book
  image         { file, width, height, sha1, source }      the book's own plate
  pictorial     { text, source }  Part II (trumps) / Part III § 2 (lesser cards): the picture and its symbolism
  traditional   { text, source }  Part I § 2 commentary on the older tarot (trumps only; null elsewhere)
  meanings[]    { scenario: "upright" | "reversed", context: "divinatory" | "additional", text, source }
}
source = { part, section?, pdfPages: [first, last] }   scan page indexes of references/pictorial-key/source/*.pdf
```

- `divinatory` meanings: Part III § 2 (lesser cards) and § 3 (trumps). `additional`: Part III § 4 (lesser cards only).
- Texts are the book's wording, with its own emphasis (`*italic*`) and without footnote markers. A passage split by a
  page break is rejoined. The "Reversed" text of a lesser card runs to the end of the book's paragraph, so any commentary
  the book prints after it is part of that text.
- Absent means the book has none; the check script lists them. Currently: `cups-02` has no reversed meaning.
- `sectionNotes` hold two remarks of the book that cover a whole section rather than one card.
- Book-wide material (suit and rank meanings, court-card colouring, recurrence of cards, spreads) is not card data and is
  not yet extracted.
